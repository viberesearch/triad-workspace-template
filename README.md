# triad-workspace-template

Шаблон рабочего репозитория для команды из двух-трёх человек, которая идёт через
многомесячную проектную программу. С репозиторием работают и люди, и их языковые
модели (Claude Code, Codex, Cursor и другие): в нём лежат общие правила, по
которым модель каждого участника делает одно и то же одинаково.

*English: a template for a small team's private workspace during a multi-month
project programme. People and their own AI coding agents work in it under one
shared set of rules (`AGENTS.md`, `rules/`). Documents are in Russian.*

## Как это устроено

Три части:

1. **Командный репозиторий** — приватный, создаётся из этого шаблона. В нём всё,
   что делает команда.
2. **Хаб программы** — репозиторий организаторов. В нём по принципу «сначала
   атомы» хранится всё сырое — транскрипты, материалы, сдачи команд — и всё,
   что из этого построено; участники его читают. Шаблон хаба:
   [cohort-hub-template](https://github.com/viberesearch/cohort-hub-template).
3. **Модель каждого участника** — работает с обоими репозиториями по правилам
   из `AGENTS.md` и `rules/`.

Схемы для тех, кто не работал с GitHub: [HOW_IT_WORKS.md](HOW_IT_WORKS.md).
Правила для людей: [PROTOCOL.md](PROTOCOL.md).

## Как начать, если вы никогда не работали с GitHub

Нужна модель, которая умеет выполнять команды на вашем компьютере: Claude Code,
Codex CLI, Cursor или похожая. Веб-чат без доступа к компьютеру настроить
репозиторий не сможет.

**Вы создаёте репозиторий команды** — скопируйте модели:

```text
Прочитай https://github.com/viberesearch/triad-workspace-template/blob/main/rules/setup_create.yaml и настрой по нему приватный репозиторий нашей команды. Я не знаю GitHub: объясняй каждый шаг простыми словами и спрашивай меня, когда нужно моё решение или действие.
```

**Вас пригласили в готовый репозиторий команды:**

```text
Прочитай https://github.com/viberesearch/triad-workspace-template/blob/main/rules/setup_join.yaml и подключи меня к репозиторию нашей команды. Я не знаю GitHub: объясняй каждый шаг простыми словами и спрашивай меня, когда нужно моё решение или действие.
```

**Каждый день** (модель запущена в папке командного репозитория):

```text
Работай по AGENTS.md. Задача: <что нужно сделать>.
```

## Что внутри

| Путь | Что это |
|---|---|
| `AGENTS.md` | Вход для модели: какой файл правил читать для какой задачи |
| `rules/` | Правила для моделей, по файлу на задачу. Обновляются из этого шаблона командой «обнови правила» |
| `rules/local/` | Правила конкретной команды. Обновления шаблона их не трогают |
| `PROTOCOL.md` | Правила для людей и что делать, если что-то пошло не так |
| `HOW_IT_WORKS.md` | Схемы: как связаны репозитории и как идёт работа |
| `journal.md` | Журнал команды: решения, договорённости, действия |
| `programme/` | Как устроена программа (заполняет команда) |
| `modules/` | По папке на модуль: подготовка, заметки, итог |
| `construction/` | Рабочая конструкция команды: позиция, карта, ставка, проверка, маршрут |
| `team/` | Состав, роли, владельцы документов |
| `sources/` | Транскрипты (дословно) и материалы |
| `archive/` | Прежние версии документов |
| `scripts/check.sh` | Проверки: секреты, дословность транскриптов, массовые удаления |
