# modules — модули и сверки

Папка на очный модуль: `NN_<место>_<ГГГГ-ММ>/`; онлайн-сверки — в `checkins/`
(файл `YYYY-MM-DD_<тема>.md`). Образцы файлов — в `_template/`.

| Файл | Когда | Что |
|---|---|---|
| `prep.md` | до модуля | цель, что везём из `construction/`, вопросы к классу и экспертам, логистика |
| `notes_YYYY-MM-DD.md` | по дням | разборы, возражения, контакты, решения |
| `outcome.md` | в конце | что изменилось в конструкции и до каких версий; действия до следующего модуля |

Транскрипты модулей — в хабе программы; здесь только ссылки на них.
