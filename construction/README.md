# construction — рабочая конструкция команды

По одному документу на элемент, без версии в имени (версия — во frontmatter).
При существенной пересборке прежняя версия уходит в `archive/`
(`rules/documents.yaml`). Файлы создаются, когда до них доходит работа.

| Файл | Элемент |
|---|---|
| `position.md` | собственная позиция команды и область ответственности |
| `system_map.md` | карта системы: область проблем → перспективная карта с разделением труда, ролями, позициями, цепочками ценности, технологическими стеками |
| `stake.md` | ставка: что должно стать возможным; каких участников, средств, условий не хватает; гипотезы для проверки |
| `validation_log.md` | журнал проверки: гипотеза → где и как проверена → что подтвердилось, изменилось, отпало |
| `project_series.md` | серия возможных проектов |
| `route.md` | маршрут и конфигурация первого действия: роли, кооперация, ближайшая внешняя проверка |
