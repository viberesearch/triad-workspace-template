# sources — первичные материалы

| Папка | Что | Правило |
|---|---|---|
| `transcripts/` | записи команды: созвоны, интервью | тело дословное; сумма — в `CHECKSUMS.sha256` (`rules/sources.yaml`) |
| `materials/` | статьи, раздатка, выжимки, копии из хаба (`materials/hub/`) | предпочтительно текст; бинарные — до 50 МБ; аудио и видео — ссылкой |

Транскрипты модулей программы — в хабе, здесь их не дублируют.
